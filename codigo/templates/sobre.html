Início Sobre Entrar

Este projeto foi criado para colocar meus conhecimentos em prática

O projeto foi desenvolvido com o objetivo de aplicar, na prática, os conceitos de desenvolvedor web, como Python, Flask, banco de dados, autentificação de usuários e CRUD.

Conheça o projeto

Objetivo do projeto

O objetivo do projeto é criar uma aplicação web que permita aos usuários gerenciar suas tarefas de forma eficiente. A aplicação deve permitir que os usuários criem, leiam, atualizem e excluam tarefas.

O que estou praticando?

Backend

Criação de rotas, sessões, autenticação e regras de acesso.

Banco de dados

Criação, consulta, alteração e exclusão de dados.

Frontend

Criação de interfaces com HTML e CSS.
